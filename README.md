# GRAM SAARTHI — Complete Browser Version

This is a self-contained static recreation of the GRAM SAARTHI interface shown in the supplied screenshots.

## Run
1. Extract the ZIP.
2. Open `index.html` directly in Chrome or Edge.
3. No npm, Vite, Node.js, build step, or internet connection is required.

## Files
- `index.html` — application shell
- `styles.css` — responsive UI styling
- `app.js` — intake form, calculations, dashboard, scheme matching, charts, persistence, and voice assistant

## Main screens
- Intake Form
- Financial Health Dashboard
- Government Schemes & Loan Readiness

## Voice assistant
Click the circular voice button. Chrome/Edge Web Speech Recognition is used when available. Example commands:
- "My name is Ravi"
- "income 50000"
- "expenses 30000"
- "household 10000"
- "EMI 6000"
- "savings 10000"
- "debt 50000"

The browser will ask for microphone permission.
